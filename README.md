
# CTDLGT - Bài tập thực hành 01

## Nội dung
- Bài 1: Tìm Max, Min, Tổng và Trung bình của 3 số nguyên.
- Bài 2: Tìm hai giá trị lớn nhất phân biệt trong dãy số.
- Bài 3: Tìm tổng đoạn con liên tiếp lớn nhất bằng Brute Force và Kadane.

## Ngôn ngữ và công cụ
- C#
- .NET
- Visual Studio Code

## Cách chạy
Mở Terminal tại thư mục gốc và chạy:

```bash
dotnet run --project Bai1
dotnet run --project Bai2
dotnet run --project Bai3 -c Release
```

## Độ phức tạp
| Bài | Thời gian | Bộ nhớ phụ |
|---|---|---|
| Bài 1 | O(1) | O(1) |
| Bài 2 | O(n) | O(1) |
| Bài 3 - Brute Force | O(n²) | O(1) |
| Bài 3 - Kadane | O(n) | O(1) |
